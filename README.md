🛒 Amazon Clone – Django Project

This is a simple Amazon-style e-commerce web application built using Python Django.
It includes user authentication, Google login, product listing, add-to-cart, and order features.

🚀 Features

User signup & login

Login using Google OAuth

Product listing page

Product details page

Add to cart

Buy now

Review & ratings

Email notifications

Mobile OTP login (Twilio)

🛠️ Tech Stack

Python 3

Django 5

SQLite

HTML / CSS

JavaScript

Bootstrap

Social Auth (Google OAuth)
